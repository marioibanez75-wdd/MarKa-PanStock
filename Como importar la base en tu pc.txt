Una vez que tenga instalado MySQL 8.0 y Python, deberá:
Primero: crear la base de datos importando el archivo.
Desde la carpeta donde descomprimió el proyecto, puede ejecutar:
mysql -u root -p < panstock.sql


Ingresará su contraseña de MySQL cuando se la solicite. Esto importa la base de datos exportada.
Segundo: configurar la conexión.
En conexion.py, tendrá que verificar que los datos de conexión correspondan a su propia instalación de MySQL. Si el código utiliza el usuario panstock_app, también tendrá que crear ese usuario en su instalación y otorgarle permisos sobre panstock, o adaptar la configuración a su usuario local.
Tercero: instalar la dependencia y ejecutar el programa.
py -m pip install mysql-connector-python
py menu.py


Si utiliza otro intérprete de Python o tiene más dependencias, habrá que ajustar ese paso.

4. Una precaución importante
Antes de entregarle el ZIP, comprobá que el archivo panstock.sql exista y tenga contenido. Y no incluyas contraseñas reales de MySQL en archivos compartidos.
Te propongo hacer primero la exportación en tu computadora. Ejecutá:
cd "C:\Users\Lenovo\Desktop\Mario Ibañez\panStock"
mysqldump -u panstock_app -p --databases panstock --routines --triggers --events > panstock.sql
